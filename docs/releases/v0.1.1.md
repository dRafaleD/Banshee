# Banshee v0.1.1

This alpha maintenance release fixes the Clippy failure in v0.1.0 and introduces
Linux/Windows release packages with SHA-256 checksums. Existing report and TOML
rule schemas remain unchanged.

## Improvements

- README workflow matrix, Windows installation instructions and exit-code guidance.
- Quick-start examples in CLI help; shell completions and a manpage in each package.
- Linux and Windows format/test/Clippy/build checks with packaged-binary smoke tests.
- Scheduled dependency auditing and automated dependency update proposals.
- Contribution and security policies, changelog, issue forms and PR guidance.

## Downloads

Choose the x86_64 Linux GNU `.tar.gz` or Windows MSVC `.zip` and download its
matching `.sha256` file. Verify the checksum before extracting. The archive
contains the binary, examples, documentation, completions and manual page.
Linux packages require a compatible glibc; these are not static/musl builds.

## Limits

Banshee remains alpha software. Findings and secret detection are heuristic.
Evidence hashes check consistency, not the identity of the evidence creator.
JWT inspection is not signature verification; certificate checks are offline
and do not query revocation services. Review sensitive output before sharing.

The v0.1.0 tag remains unchanged. This release includes its CI lint correction.
